# 채널 브리프

## 메시지
AI가 발전할수록 "할 수 있느냐"는 문제가 사라지고 "무엇을 떠올리느냐"만 남는다. 병목은 기술이 아니라 인간의 상상력이다. 그러니 지금부터 상상하는 연습을 하자.
- 이 채널이 남길 감정: "와, 이런 것도 되는구나" → "나라면 뭘 해볼까".
- 설교하지 않는다. 메시지는 사례가 스스로 말하게 하고, 마지막 장에서 한 번만 짧게 말한다.

## 독자
- 80% 일반인: AI를 뉴스로만 접했거나 ChatGPT를 가끔 쓰는 사람. 용어 없이 이해돼야 한다("LLM", "프롬프트 엔지니어링", "에이전트" 같은 말은 풀어 쓰거나 뺀다).
- 20% 실무자: 6장 "직접 해보기" 박스에서 도구·시간·비용·첫 한 줄을 얻어간다.

## 말투
- 친구가 휴대폰 화면을 내밀며 "이거 봤어?" 하는 톤. 문장은 짧고 담백하게, ~다 체로 통일.
- 슬라이드 한 장의 본문은 최대 3문장(약 90자). 한 줄 ≤ 18자, 줄바꿈은 직접.
- 금지: 느낌표, 이모지, "놀랍게도", "숨겨진", "충격", "AI 시대 필수", "N가지", 반말 명령형("해봐"), 대칭 나열("A도, B도, C도").

## 캐러셀 공식 (한 편 = 사례 하나, 기본 8장)
| 장 | 레이아웃 | 역할 |
|---|---|---|
| 1 | `hook` | 결과물 이미지 + 구체적인 헤드라인(5~8단어). 의외의 사실이나 질문 하나. 답은 7장에서 |
| 2 | `person` | 누가, 어떤 불편·호기심에서 시작했나 |
| 3 | `steps`/`evidence` | 무엇을 했나 — 우리가 그린 단계 그래픽, 원본 캡처는 액자 + 출처 칩 |
| 4 | `compare`/`evidence` | 결과 — 전/후, 숫자, 반응 |
| 5 | `steps`/`quote` | 핵심 발상 — 남들이 안 떠올린 한 가지 |
| 6 | `tryit` | 직접 해보기(실무자용): 도구 · 걸린 시간/비용 · 첫 한 줄 |
| 7 | `insight` | 1장의 질문에 답: 도구는 누구나 가졌다, 달랐던 건 떠올린 사람 |
| 8 | `closing` | 채널 메시지 한 줄 + 공유 CTA("이걸 떠올릴 것 같은 사람에게 보내주세요") + 팔로우 한 줄 |
- 원본 이미지를 쓴 장이 절반을 넘지 않게 한다. 3~5장 중 최소 2장은 순수 해설 그래픽.
- 연결 점검: 1장부터 8장까지 본문만 이어 읽었을 때 한 편의 이야기가 되는가, 인접한 두 장이 인과·대조로 이어지는가.

## 캡션
- 첫 줄 = 1장 헤드라인. 이어서 사실(누가·언제·어디서·무슨 도구), 슬라이드에서 단순화한 부분의 정정, 출처(매체명 + 원작자 계정).
- 400~700자, 문장 길이를 섞는다. 해시태그 3~5개(인스타 한도 5개).
- 확인이 덜 된 항목은 마지막 줄 `(게시 전 확인: …)` — 복붙본에서 자동 제외된다.
- 원작자가 인스타에 있으면 게시할 때 Collab 초대 또는 태그를 권한다(캡션 확인 메모에 적는다).

## 사례 선정 점수 (각 1~5, 합 20점 이상만 제작)
공유욕(친구에게 보낼 만한가, 카톡 한 줄 테스트) · 검증(1차 출처) · 시각자료(보여줄 결과물) · 최신성(최근 12개월) · 메시지연결("기술이 아니라 발상"으로 이어지나). 백로그는 일반 8 : 업무 2 비율.
