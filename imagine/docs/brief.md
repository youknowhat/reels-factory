# 채널 브리프

## 메시지
AI가 발전할수록 "할 수 있느냐"는 문제가 사라지고 "무엇을 떠올리느냐"만 남는다. 병목은 기술이 아니라 인간의 상상력이다. 그러니 지금부터 상상하는 연습을 하자.
- 이 채널이 남길 감정: "와, 이런 것도 되는구나" → "나라면 뭘 해볼까".
- 설교하지 않는다. 메시지는 사례가 스스로 말하게 하고, 마지막 장에서 한 번만 짧게 말한다.

## 독자
- 80% 일반인: AI를 뉴스로만 접했거나 ChatGPT를 가끔 쓰는 사람. 용어 없이 이해돼야 한다("LLM", "프롬프트 엔지니어링", "에이전트" 같은 말은 풀어 쓰거나 뺀다).
- 20% 실무자: '따라 하기' 장과 캡션의 질문 틀·도구·시간·비용에서 얻어간다.

## 말투
- 친구가 휴대폰 화면을 내밀며 "이거 봤어?" 하는 톤. 문장은 짧고 담백하게, ~다 체로 통일.
- 슬라이드 한 장 = 헤드라인 2~3줄(한 줄 ≤ 14자) + 서브 한 줄. 설명은 캡션으로.
- 금지: 느낌표, 이모지, "놀랍게도", "숨겨진", "충격", "AI 시대 필수", "N가지", 반말 명령형("해봐"), 대칭 나열("A도, B도, C도").

## 캐러셀 공식 — 미니멀 매거진 피드 (한 편 = 사례 하나, 7~8장)
레퍼런스: @artart.today. **이미지가 훅, 글자는 두 줄, 이야기의 세부는 캡션.** 모든 장이 같은 문법: 풀블리드 비주얼 + 하단 흰 글씨 헤드라인 2~3줄 + 회색 서브 한 줄 + 하단 가운데 라벨 `상상한도 | AI`. 내지는 좌상단 브랜드.
- 레이아웃은 두 개뿐: `photo`(image / chat / doc / quote 중 하나 + headline + sub), `closing`.
- **1장(표지):** 가장 강한 이미지 + "누가 AI로 무엇을" 이 드러나는 구체적인 두 줄. 3초 안에 AI 이야기임이 보여야 한다(헤드라인·서브에 AI/도구 이름, 또는 대화창).
- **2~7장:** 장마다 이미지 하나 + 한 줄. 1장이 던진 궁금증의 답(반전·핵심 발상)은 **반드시 슬라이드에** 남긴다 — 공유와 저장은 슬라이드에서 결정된다.
- **따라 하기 한 장(실무자용):** 원래 사례를 재현하지 않는다. 우리가 **가상의 예시**로 같은 방법을 써본 화면을 캡처하고 "우리가 해본 결과"라고 밝힌다. 틀·프롬프트 전문은 캡션.
- **8장(closing):** 메시지 한 문장 + 공유 CTA(누구에게 보낼지 구체적으로) + 팔로우.

### 이미지 원칙
| 종류 | credits `own` | 용도 |
|---|---|---|
| 원작 이미지(기사 사진·원작자 게시물·결과물 캡처) | false | 표지, 결정적 장면. **장수의 절반 이하**, 우상단 출처 필수 |
| 재구성 그래픽(대화창·문서 카드 등, 렌더러가 그림) | — (이미지 아님) | 과정 설명. 재구성임을 라벨/캡션에 밝힌다. AI의 답은 지어내지 않는다 |
| 우리 시연 캡처 | true | 따라 하기. 실존 인물 정보 금지, 가상 예시만 |
- 이미지는 `fetch_assets.py`로 받는다(로컬). `src`(직접) / `og`(기사 대표 이미지) / `shot`(페이지 캡처) / 없으면 `want`에 적어두고 수동.
- 저작권: 보도 사진은 인용 범위(출처 명시, 해설의 일부)로만. 원작자가 인스타에 있으면 Collab 초대를 우선 검토.

## 캡션
- 첫 줄 = 1장 헤드라인. 이어서 사실(누가·언제·어디서·무슨 도구), 슬라이드에서 단순화한 부분의 정정, 출처(매체명 + 원작자 계정).
- 400~700자, 문장 길이를 섞는다. 해시태그 3~5개(인스타 한도 5개).
- 확인이 덜 된 항목은 마지막 줄 `(게시 전 확인: …)` — 복붙본에서 자동 제외된다.
- 원작자가 인스타에 있으면 게시할 때 Collab 초대 또는 태그를 권한다(캡션 확인 메모에 적는다).

## 사례 선정 점수 (각 1~5, 합 20점 이상만 제작)
공유욕(친구에게 보낼 만한가, 카톡 한 줄 테스트) · 검증(1차 출처) · 시각자료(보여줄 결과물) · 최신성(최근 12개월) · 메시지연결("기술이 아니라 발상"으로 이어지나). 백로그는 일반 8 : 업무 2 비율.
