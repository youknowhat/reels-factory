# 인스타그램 프로필 (후보 — 사용자 선택 대기)

형식: 핸들 / 프로필 이름 / 소개 2줄 / 프로필 사진 방향. 컨셉이 바뀌면 이전 안은 지우지 말고 "폐기"로 표시한다.

## A. 상상한도
- 핸들: `@sangsang.hando` (대안 `@imagination.limit`)
- 이름: 상상한도
- 소개: 할 수 있는 건 이미 충분히 많아졌어요 / 이제 한도는 상상력입니다
- 사진: 오프화이트 바탕에 손글씨 느낌 없는 굵은 "∞" 대신 **빈 괄호 "( )"** — "여기에 무엇을 넣을지는 당신"
- 장점: 신용한도 말장난이라 한 번에 기억됨. "당신의 상상 한도는?"이 매 편 클로징 문장으로 자연스럽게 이어짐.

## B. 다음 상상

- 이름: 다음 상상
- 소개: 누군가 먼저 상상했고, AI가 만들었습니다 / 다음 상상은 당신 차례
- 사진: 두 개의 따옴표 중 하나만 채워진 모양
- 장점: 차분하고 오래 가는 이름. 약점: 기억에 남는 힘은 A보다 약함.

- 장점: 사례형 콘텐츠의 반응("이게 돼?")을 그대로 이름으로. 약점: 메시지(상상력)보다 놀람에 초점이 가서 흔한 AI 정보 계정처럼 보일 위험.
